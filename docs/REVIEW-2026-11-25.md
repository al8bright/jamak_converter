2. **문서 숫자**: lock 패키지 수를 50개에서 51개로 고쳤습니다(qwen-asr 포함). `models.py`의 잘못된 TODO 참조도 고쳤습니다.

## 2. 고치면 좋은 것 (중간)

### 보안
- **모델 목록 조회가 키의 서비스와 `kind`가 같은지 확인하지 않음**: 상태 버그가 나면 OpenAI 키가 api.x.ai로 갈 수 있습니다(`server.py:604-640`). `_secret_for`에서 provider가 같은지 확인하면 됩니다.
- **HF 모델 다운로드에 리비전 고정과 해시 검증이 없음**(`installer.py:398`). 모듈 설명에는 모두 SHA-256으로 확인한다고 적혀 있어 실제 동작과 다릅니다. 결정은 6장 E2에 있습니다.
- **키 가림 처리에 빈틈이 있음**
  - h11이 CR이나 NUL이 들어간 헤더를 repr로 내보내면 가림 처리를 통과합니다.
  - `last_test`와 WebSocket 오류 문구는 가림 처리를 아예 거치지 않습니다.
  - 해결책: 키를 저장할 때 `[\x21-\x7e]+`만 허용하고, check 응답은 고정 문구로 돌려줍니다.
- **1000자가 넘는 키를 붙이면 422 응답의 `input`에 키 원문이 들어감**: 검증 오류 핸들러에서 `input`을 빼면 됩니다.
- **하위 프로세스가 `*_API_KEY`와 `JAMAK_TOKEN`을 그대로 물려받음**: 대상은 Qwen 작업 프로세스, uv, torch 확인입니다(`qwen_asr.py:244`, `installer.py:510, 521`).

### 내려받기·배포
- **`present()`를 너무 너그럽게 판정함**: Qwen은 샤드 하나만, Whisper는 `model.bin`만 있어도 "받음"으로 봅니다(`models.py:91`).
- **설치가 두 번 동시에 시작될 수 있음**: `install()`의 확인부터 스레드 시작까지가 lock 밖에 있습니다(`installer.py:639`).
- **CUDA를 지울 때 이미 로드된 DLL은 지워지지 않는데 성공으로 보고함**(`installer.py:311`).
- **디스크 계산이 어긋남**
  - 디스크 여유 검사가 PyTorch 실제 최고 사용량(7GB 이상)보다 작게 봅니다.
  - 실패하거나 취소하면 `torch-runtime.new`와 uv-cache가 남습니다.
  - 심볼릭 링크가 있는 PC에서는 크기를 두 번 셉니다(`installer.py:158`).
- **uv가 사용자 환경의 `UV_*` 변수와 프록시 설정을 다르게 받음**: 회사망에서는 PyTorch 받기만 실패할 수 있습니다.

### 음성 인식
- **Qwen 정렬 결과와 원문의 표기 차이로 구두점과 공백이 빠짐**: 정렬기가 원문을 NFKC로 정규화하기 때문입니다. 예: `ＯＫ。`, `I love you` → `Iloveyou`(`qwen_asr.py:105`).
- **긴 발화를 25초마다 기계적으로 자름**: 단어 중간이 잘리고, 청크 경계에서 단어 순서가 섞일 수 있습니다. `max_speech_duration_s`를 쓰고 단어 시간을 청크 범위로 제한하면 됩니다(`qwen_asr.py:50`).
- **`max_new_tokens=256`이 60초 청크에서 결과를 자름**(`worker:45`).
- **기존 필터(무음·반복·환각 문구)가 Qwen 구간에는 사실상 걸리지 않음**: 버린 청크도 `filtered.json`에 남지 않습니다.

### 클라우드 번역
- **429를 기다리지 않고 바로 재시도함**: `Retry-After`도 무시합니다(`base.py:300`).
- **Papago 오류 코드를 잘못 처리함**
  - 실제 한도 초과는 errorCode `400`입니다. `410`과 `420`은 일시적인 제한이라 다시 시도하면 됩니다.
  - `N2MT10`은 한도가 아니라 용어집 키 오류입니다(`mt_api.py:123`).
- **Papago 글자 수가 두 번 청구될 수 있음**: 줄 수가 맞지 않으면 한 줄씩 다시 보내기 때문입니다.
- **대체로 넘어갈 때 1차 사용량이 사라짐**: 진행 화면에 비용이 "—"로 나옵니다(`pipeline.py:296`).
- **OpenAI 거절을 거절로 처리하지 않음**: `message.refusal`이 아니라 번역 실패로 흘러갑니다.
- **DeepSeek 모델 힌트가 낡음**: `deepseek-chat`은 폐기가 공지된 모델입니다.
- **JSON이 아닌 200 응답과 연결 끊김을 재시도하지 않음**: 작업이 바로 멈춥니다.

### 용어집
- 순서만 바꿔도 "용어집이 바뀌었습니다"가 뜨고 전체를 다시 번역합니다(클라우드 비용 발생).
- 짧은 별칭이 엉뚱한 파일 이름에 자동 추천됩니다. 예: `op`이 "Shop Girl"에 걸립니다.
- 저장하지 않은 편집이 사라지는 경로가 있습니다: 이름 바꾸기, 복제, 사이드바 이동, 칩 클릭.

- **하드코딩된 서비스 이름**
  - 진행 표시가 OpenAI나 DeepL을 쓸 때도 "Gemini API"로 나옵니다(`App.tsx:195`).
  - 검수 화면 `MODE_LABEL`에 새 서비스가 빠져 있습니다(`Review.tsx:10`).
  - `api.ts`가 백엔드 서비스 목록을 복제하고 있고, Claude 모델 기본값도 서로 다릅니다.
- **편집기의 모델 목록 effect**: catch가 없고, 늦게 온 응답이 새 목록을 덮어씁니다(`Settings.tsx:272`).
- **select 값이 선택지에 없는 상태**
  - 동시 요청 8인 채로 로컬로 바꿀 때
  - 대체 대상 프로필을 지웠을 때
  - 쓰던 키를 지웠을 때
- **새 프로필에서 "연결 테스트"를 누르면 편집기가 다시 마운트됨**: 진행 표시가 사라집니다.
- **오류 처리가 없는 곳이 여러 개임**: Glossary 저장과 삭제, Options 처음 불러오기, provider 목록.

### 사용 흐름·문구
- **오류가 영어 예외 원문 그대로 나옴**: 예: `AuthenticationError: Error code: 401`, `InstallError: SHA-256 mismatch`. 영어 진행 로그도 있습니다. 어떻게 고치는지 알려 주는 문장으로 바꿔야 합니다.
- **Qwen을 받을 때 실제 비용이 안 보임**: 버튼에는 6.2GB로 나오지만 PyTorch까지 받으면 8.9GB이고, 설치 후 디스크는 약 10.7GB를 씁니다.
- **서비스 이름 뒤 조사 "으로"가 9곳 중 7곳에서 틀림**: 예: "OpenAI으로". 문장을 "{이름} 서버로 보냅니다"로 바꾸면 됩니다.
- **모델 설명이 근거보다 단정적임**: 측정은 영화 한 편과 3분 구간뿐입니다. Gemma의 "GPU 메모리 약 9GB"는 실측 12.5GB와 다릅니다.
- **같은 대상을 여러 말로 부름**: 받기/내려받기/다운로드, 삭제/지우기, 엔진의 세 가지 뜻, VRAM/GPU 메모리.
